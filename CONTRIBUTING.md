# Contributing to Network Search

Thank you for your interest in contributing to Network Search! We appreciate your help in making this plugin better.

## Code of Conduct

Please be respectful and constructive in all interactions.

## How to Contribute

### Reporting Bugs

1. **Check existing issues** - Make sure the bug hasn't already been reported
2. **Create a detailed issue** with:
   - Clear description of the bug
   - Steps to reproduce
   - Expected vs actual behavior
   - WordPress version, PHP version, and plugin version
   - Any error messages or logs

### Submitting Features

1. **Open an issue** to discuss the feature first
2. **Describe the use case** and why it's needed
3. **Wait for feedback** before starting development

### Code Contribution

1. **Fork the repository**
2. **Create a feature branch**: `git checkout -b feature/your-feature-name`
3. **Make your changes** following the coding standards
4. **Test thoroughly** before submitting
5. **Submit a pull request** with a clear description

## Coding Standards

- Follow WordPress PHP coding standards
- Use proper security functions (sanitize, escape, validate)
- Add PHPDoc comments to all functions and classes
- Use meaningful variable and function names
- Keep code clean and DRY (Don't Repeat Yourself)

## Testing

- Test with sample CSV data
- Test import/replace modes
- Test search functionality
- Test on different screen sizes
- Check browser console for errors

## Pull Request Process

1. Update README.md if needed
2. Add comments explaining complex logic
3. Ensure all files follow coding standards
4. Provide a clear PR description
5. Link to any related issues

## Questions?

Feel free to open an issue with your question. We're here to help!

Thank you for contributing!
